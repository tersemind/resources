# Norvig count_1w frequency data provenance

Source: [Natural Language Corpus Data](https://www.norvig.com/ngrams/). Data: [count_1w.txt](https://www.norvig.com/ngrams/count_1w.txt). The author describes the data as derived from the Google Web Trillion Word Corpus. The MIT license on the page explicitly applies to code and cannot simply be treated as an MIT license for the count_1w.txt data.

This repository preserves the original frequency-table snapshot used by infra and records its hash and provenance. The data publisher's terms determine the scope of use. This record grants no additional permissions.
