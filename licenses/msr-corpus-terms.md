# Scope of use for the MSR corpus

File: `assets/corpus/msr-training-872a24b0aa82.utf8`.

The source mirror's README preserves the SIGHAN Bakeoff 2005 data distribution terms: the corpus is provided for that competition's purposes, and other uses require permission from the original data provider. Microsoft Research is the provider of the MSR portion. Availability from a download mirror does not grant additional use or redistribution rights.

This repository preserves the original file matching infra's checksum and includes it in the resource inventory and manual upload workflow. Use and redistribution remain subject to the original terms and the data provider's authorization.

- [Source mirror and terms](https://raw.githubusercontent.com/yuikns/icwb2-data/master/README.md), Licensing section
- [Original competition website](http://sighan.cs.uchicago.edu/bakeoff2005/)

This is a provenance record for the terms, not a new license or authorization.
